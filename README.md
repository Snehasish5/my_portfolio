## Features

- **Responsive Design** — Works across desktop and mobile screens
- **Smooth Navigation** — Sticky navbar with section-based scroll links
- **Typed.js Hero** — Animated role titles (Full Stack Developer, Data Analyst, Backend Developer)
- **About Section** — Personal introduction with key stats (Hackathons, Projects)
- **Timeline Experience** — Vertical timeline of professional & academic milestones
- **Technical Skills** — Icon cards with hover proficiency tooltips & animated progress bars
- **Professional Skills** — Animated SVG donut charts (Communication, Teamwork, Project Management, Time Management)
- **Project Carousel** — Sliding cards for 9+ projects with Live View & GitHub links
- **Contact Footer** — Email, phone, location, and social media connect cards

## Getting Started

No build tools or server needed — it's a pure static website.

```bash
# Clone the repository
git clone https://github.com/Snehasish5/my_portfolio.git

# Navigate into the project
cd portfolio

# Open in browser
start index.html   # Windows
open index.html    # macOS
```
